# AlphAI plugin for Claude

This folder is the Claude Code plugin that the Claude plugin directory lists:
the hosted AlphAI MCP server (`.mcp.json`) and five finance skills (`skills/`).
It holds only what the directory accepts from a community plugin. The Cursor,
Gemini CLI and Open Plugins manifests live at the repository root.

Install from Claude Code:

```
/plugin marketplace add makeev/alphai-plugin
/plugin install alphai@alphai
```

The skills are mirrored from
[makeev/alphai-claude-skills](https://github.com/makeev/alphai-claude-skills),
the canonical source. Full documentation: the
[repository README](https://github.com/makeev/alphai-plugin#readme) and
[alphai.io/developers](https://alphai.io/developers).
